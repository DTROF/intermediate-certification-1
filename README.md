## Анализ данных промышленного оборудования и аварийных остановок

# Цель работы — проанализировать данные промышленного оборудования и проверить, можно ли использовать показания датчиков для определения аварийных остановок.

### Файлы проекта

# - `01_prepare_machine_failure_dataset.sql` — подготовка данных и создание VIEW в PostgreSQL.
# - `02_machine_failure_analysis.ipynb` — загрузка данных, EDA, очистка, визуализация и проверка гипотез.
# - `machine_failure_dataset.csv` — итоговый датасет, выгруженный из PostgreSQL для анализа в Python.

# Целевая переменная — `is_breakdown`:
# - `0` — обычное событие;
# - `1` — аварийная остановка.
